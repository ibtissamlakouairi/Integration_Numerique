# Numerical Integration

This project contains two Python programs for the numerical computation of integrals.

## Files

- `trapeze.py`: Implements the simple and composite trapezoidal rules.
- `simpson.py`: Implements Simpson's rule and the composite Simpson's rule.

## Libraries Used

- NumPy
- Matplotlib

## Execution

To run the trapezoidal method program:

```bash
python trapeze.py
```

To run the Simpson's method program:

```bash
python simpson.py
```
